# sr-python-tools
社労士・HR業務の自動化ツール集

---

## 📂 ツール一覧

### 🆕 8. 雇用保険料率 年次自動更新（update_koyo_rates.py）
- GitHub Actionsにより毎年3月1日に自動実行
- 厚生労働省公式PDFからPDF URLを動的に検索・取得
- 3業種（一般・農林水産清酒製造・建設）に対応
- 更新結果をメールで通知（成功・失敗どちらも通知）
- 取得結果を`雇用保険料率_最新.json`に保存しStreamlitアプリに自動反映

### 🆕 7. 社会保険料一括計算 Webアプリ（streamlit_app/）
- ブラウザで動くWebアプリ（Streamlit）
- 複数名の社会保険料を一括計算・Excel出力
- **従業員負担**：健康保険・介護保険・厚生年金・雇用保険・手取り概算
- **事業主負担**：会社負担合計・人件費総額（パスワード認証で解放）
- 47都道府県の協会けんぽ料率に対応（令和8年度・自動取得）
- 子ども・子育て支援金の適用タイミング切り替え（4月分・5月分以降）
- 雇用保険料率は毎年3月にGitHub Actionsで自動更新

### 6. 雇用保険料率自動取得（雇用保険料率自動取得.ipynb）
- 厚生労働省公式PDFから料率を自動取得・前年度比較レポートを生成
- 取得した料率をJSONに保存（雇用保険料率_令和〇年度.json）

### 5. 社会保険料計算（社会保険料2025.ipynb / 社会保険料率(協会けんぽ)取得2026.ipynb）
- 令和8年度最新料率で自動計算・47都道府県対応
- 協会けんぽのExcelファイルを自動ダウンロード
- 法律に基づく正しい端数処理（健保・年金：四捨五入／雇用保険：切り捨て）
- 子ども・子育て支援金対応・4月・5月分を2シートで出力

### 4. 法令条文検索ツール（e-Gov法令API.ipynb）
- e-Gov法令APIを使用・法律名・条文内をキーワードで検索

### 3. 給与計算自動化（月給を自動計算して列を追加.ipynb）
- 出勤日数・残業時間から月給・残業代・支給合計を自動計算
- 部署別集計・グラフ自動生成

### 2. 勤怠データ自動クリーニング（エクセルデータ集計.ipynb）
- 全角スペース・全角数字・大文字小文字の混在を自動修正
- 重複行・空欄を自動検出・クリーニング済みデータをExcelに書き出し

### 1. 郵便番号→住所自動補完（APIの練習.ipynb）
- 郵便番号を入力するだけで住所・ふりがなを自動取得
- 複数件の一括処理に対応・Excelに自動書き出し
