# sr-python-tools
社労士業務自動化ツール集
## 収録ツール

### 1. 郵便番号→住所自動補完（APIの練習.ipynb）
- 郵便番号を入力するだけで住所・ふりがなを自動取得
- 複数件の一括処理に対応
- 取得結果をExcelに自動書き出し

### 2. 勤怠データ自動クリーニング（エクセルデータ集計.ipynb）
- 全角スペース・全角数字・大文字小文字の混在を自動修正
- 重複行・空欄を自動検出
- クリーニング済みデータをExcelに書き出し

### 3. 給与計算自動化（月給を自動計算して列を追加.ipynb）
- 出勤日数・残業時間から月給・残業代・支給合計を自動計算
- 部署別集計・グラフ自動生成

### 4. 法令条文検索ツール（e-Gov法令API.ipynb）
- e-Gov法令APIを使用
- 法律名をキーワードで検索
- 条文内をキーワードで絞り込み

### 5. 社会保険料計算ツール（社会保険料2025.ipynb,社会保険料率(協会けんぽ)取得2026.ipynb）
- 令和8年度最新料率で自動計算
- 協会けんぽのExcelファイルを自動ダウンロード
- 47都道府県の健康保険料率に対応
- 法律に基づく正しい端数処理を実装
  - 健康保険・厚生年金：四捨五入（健康保険法第167条・厚生年金保険法第84条）
  - 雇用保険：切り捨て（雇用保険法第32条）
- 子ども・子育て支援金（令和8年度新設）の適用タイミング切り替え対応
- 4月支払い分・5月支払い分を2シートで自動書き出し

### 6. 雇用保険料率自動取得ツール（雇用保険料率自動取得.ipynb）
- 厚生労働省公式PDFから雇用保険料率を自動取得
- 3業種（一般・農林水産清酒製造・建設）すべてに対応
- 法律に基づく正しい端数処理を実装
  - 雇用保険：切り捨て（雇用保険法第32条）
- 前年度との比較レポートを自動生成
- 取得した料率をJSONファイルに保存（翌年度の自動比較用 雇用保険料率_令和8年度.json）
- 毎年4月の改定時に実行するだけで最新料率に自動更新
